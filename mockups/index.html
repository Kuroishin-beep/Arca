Turning these into the Next.js app

  1. Copy the :root block from tokens.css into app/globals.css, and re-enable Tailwind preflight (delete the four base rules the mockups add for the CDN build).
  2. Copy theme.extend from tailwind.config.js into tailwind.config.ts. Class names stay identical, so no markup changes.
  3. Every element marked data-component="X" becomes src/components/<level>/X.tsx, with the props listed in Design.md Step E.
  4. Swap the hard-coded rows for items.map() with key={item.id}. The markup does not change.
  5. Rename attributes for JSX: class → className, for → htmlFor, inline style to an object. data-* and aria-* carry over unchanged.
  6. Each .sr-only span on an icon-only button becomes that button's aria-label.
  7. Replace the three modals with Radix Dialog for focus trapping and Esc handling — keep the markup inside.
  8. Delete the .mock-frame / .mock-label rules. Nothing else in tokens.css is mockup-only.
